# esp32sim 中文文档

本目录是 esp32sim 文档的简体中文翻译，非官方版本。译文对应 v0.4.0，如有出入以上游为准。

上游英文文档见仓库的 [docs/](../README.md)。译文里的内部链接一律指向上游英文原文，例如 `../cli.md` 打开的是仓库里的英文版。

| [getting-started.zh-CN.md](getting-started.zh-CN.md) | 入门指南：构建 esp32sim、在每款芯片上跑固件、脚本、WiFi、浏览器构建、实时开发板 UI 与调试 |
| [cli.zh-CN.md](cli.zh-CN.md) | 命令行参考：全部参数、环境变量、动作脚本、USB host 与协处理器、摄像头与 I2S 输入 |
